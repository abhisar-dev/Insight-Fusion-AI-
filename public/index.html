1. Mathematical Formulation of the Source Reliability Index

The system deterministically evaluates each institutional or empirical source $S_i$ using an algorithmic linear combination of four normalized parameters:

Reliability(S) = (0.40 × DomainAuthority) + (0.25 × RecencyWeight) + (0.25 × ConsensusCrossVerif) + (0.10 × EmpiricalRigor)
  • Domain Authority (40%): Hardcoded registry rating based on statutory authority (e.g. .gov.in = 98, ieee.org = 97, ilo.org = 96).
  • Recency Weight (25%): Exponential decay penalty $\max(70, 100 - 5 \times \Delta t_{\text{years}})$.
  • Consensus Cross-Verification (25%): Inverse distance to the consensus cluster centroid across verified nodes.
  • Empirical Rigor (10%): Audited presence of primary datasets vs narrative policy commentary.

2. Contradiction Isolation & Divergence Delta Formula

When two claims $C_A$ and $C_B$ exhibit opposite statistical polarity, the system creates a Contradiction Ledger entry and evaluates the divergence gap:

DivergenceGap(C_A, C_B) = (|Claim_A - Claim_B| / max(Claim_A, Claim_B)) × 100%

3. Zero-Hallucination Retrieval-Augmented Generation (RAG) Bound

Generation is strictly bounded to the convex hull of retrieved primary chunks. If the cosine similarity $\cos(\vec{q}, \vec{d}) < 0.82$, the system triggers an Epistemic Humility fallback rather than generating speculative tokens.
